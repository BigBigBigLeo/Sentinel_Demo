# Sentinel 7.3 · 全域战备指挥中心（Mission Control）架构重构与版面规范方案

> **系统定位**：云南澄江 900 亩数字蓝莓超级工厂 · 战略全景作战座舱（Common Operating Picture, COP）  
> **设计哲学**：深度融合 **Palantir Foundry / AIP** 的“业务本体驱动与统一作战态势”理念，以及 **John Deere Operations Center / 荷兰 Priva / Samsara** 的高频现代工业软件交互范式。

---

## 1. 核心架构重构：指挥中心与微观流程的彻底解耦

### 1.1 概念纠偏：座舱（Flight Deck）vs 流程（Pipeline）
- **原有缺陷**：系统此前将“指挥中心”放置在工作流的第一步（`[1. 指挥中心 -> 2. 传感 -> 3. 风险 -> 4. 处方...]`），混淆了**战略宏观座舱**与**微观工单推演流水线**的边界。
- **重构原则**：
  - **指挥中心（Mission Control）是 Level 0 的战略作战大厅**。它 7×24 小时统摄全园空间、商业、要素与资本，永远处于最高层级，不属于任何单一农事或单一订单。
  - **六阶决策与执行环（OODA Loop）是 Level 1 的微观事件闭环流水线**。它是处置某个具体地块异常、某批特定订单冲突的作业工具链。

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│               🛰️ LEVEL 0: 全域战备指挥中心 (Common Operating Picture - COP)            │
│                 全园空间态势 · 在手订单交付 · 关键资源调度 · 实时金融风控              │
└───────────────────────────────────────────┬────────────────────────────────────────────┘
                                            │ 1-Click 战略穿透与下钻 (Drill-Down)
┌───────────────────────────────────────────┴────────────────────────────────────────────┐
│                    LEVEL 1: 六阶微观决策与作业流水线 (Operational OODA Loop)           │
│                                                                                        │
│   [1. 感知遥测] ➔ [2. 认知研判] ➔ [3. 处方决策] ➔ [4. 派发执行] ➔ [5. 存证审计] ➔ [6. 历史复盘]  │
│    (/sensors)      (/risk)       (/prescription)  (/execution)    (/audit)       (/history)    │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

### 1.2 导航系统的重组定义
1. **全局侧边栏（Sidebar）**：
   - 顶部单设独立且醒目的 **`[ 🛰️ 指挥中心 (Mission Control) ]`**（带有全域实时告警徽标）。
   - 下方展开 6 个具体 OODA 作业阶段：
     - `1. OBSERVE 感知层`：传感遥测 (`/sensors`)、全域情报 (`/intelligence`)
     - `2. ORIENT 认知层`：业务与订单 (`/business`)、风险研判 (`/risk`)
     - `3. DECIDE 决策层`：处方决策矩阵 (`/prescription`)、情景推演沙盒 (`/scenarios`)
     - `4. ACT 执行层`：自治派发调度 (`/execution`)
     - `5. PROVE 存证层`：审计溯源凭证 (`/audit`)、历史复盘全景 (`/history`)
     - `6. GOVERN 治理层`：策略规则沙盘 (`/admin`)
2. **流程面包屑（PipelineBreadcrumb）**：
   - 仅在具体流程页面（如 `/risk`、`/prescription` 等）出现，连接具体的作业环节；
   - 在指挥中心首页，展示专属的 **“全域战备态势总揽 · 跨流程全局指挥大厅”** 战略通告状态条。

## 4. 高频管理流程与“1-Click 穿透下钻（Drill-Down）”

为杜绝“信息堆砌却无法操作”的弊病，指挥中心提供 4 个最高频的一键穿透操作流：

1. **地块微气候探针穿透**：
   - 悬停/点击 A 区任一地块（如 LOT-01）：即刻展开气温、湿度、VPD 饱和气压差、叶面湿润时长，支持一键点击 `[调阅地块传感详情 ➔ /sensors]`。
2. **冲突险情工单直通推演**：
   - 看到 LOT-03 处于红牌隔离状态，顶部警报栏出现醒目发光提示：点击 `[前往方案决策室 ➔ /prescription]`，直接加载该冲突工单进行 A/B/C 三方案推演与放行。
3. **订单履约全貌对账**：
   - 点击订单总控台的任何订单条目：一键穿透直达 `[农场经营与订单大盘 ➔ /business]` 查看详细的片区配给与批次凭证。
4. **一键安全返回指挥中心**：
   - 在任何下级页面（`/prescription`、`/execution`、`/admin` 等），导航栏顶部始终保留 `[ 🛰️ 战备指挥大厅 ]`，管理者处理完微观事务后，1 秒即可无缝回舱。
