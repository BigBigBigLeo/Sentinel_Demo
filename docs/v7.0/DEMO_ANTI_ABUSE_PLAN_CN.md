## 二、 核心机制详解

### 1. 体验额度计数器（给公网访客看，建立心理预期）
在右侧 Ask Sentinel AI 提问抽屉上方，设置一个清晰精致的工业风指示徽章：
```
┌──────────────────────────────────────────────────────────────┐
│ 🤖 Sentinel AI 决策顾问                 [公网体验额度: 5/5]  │
│ 本对话仅限蓝莓农场农艺、合规与经营决策问答。                 │
└──────────────────────────────────────────────────────────────┘
```
*   普通公网访客每提问一次，数字减 1（保存在该访客浏览器的 `sessionStorage` + IP 校验）；
*   提问后，输入框禁用并显示 **5 秒倒计时冷却**（`请稍候 5s...`），彻底阻断连续敲击回车或恶意脚本；
*   5 次用尽后，输入框变为灰色锁定状态，提示：
    *   *“您已体验完 5 次对话演示。如需继续自由研判，可切换为离线仿真模式或在控制台输入演示口令。”*

---

### 2. “演示者口令模式” (Presenter Mode · 专为您设计的 VIP 绿色通道)
**这是解决“既要防外人乱刷，又要保证您自己现场演讲演示流畅”的最佳方案：**
*   在 AI 抽屉的右上角，有一个隐蔽的小钥匙图标 `🔑`；
*   您在自己电脑、平板或现场大屏上演示时，点击输入您设定的**专属演示口令**（例如 `sentinel2026`，在 Vercel 环境变量中配置 `PRESENTER_PASSPHRASE`）；
*   **一旦口令验证通过：**
    *   该浏览器立即解锁为 **“👑 演示者模式 (Presenter VIP)”**；
    *   **解除 5 次提问上限**，无限制随意自由提问；
    *   **解除 5 秒冷却**；
    *   而公网上的其他陌生人没有口令，依然被严格限制在 5 次以内！

---

### 3. 话题范围严格锁死（防被当成免费 ChatGPT 薅羊毛）
很多公网 AI Demo 最怕被羊毛党用来：
*   丢一篇几千字的高考英语作文要求改错；
*   丢一段 Python 代码要求找 Bug；
*   要求“以猫娘口吻写一篇爱情小说”。

**观衡智序的三重输入输出卡扣：**
1.  **输入字符硬截断：** 输入框设置 `maxLength={150}`，超出 150 字直接无法输入，从物理上杜绝大文本灌入。
2.  **单次回复硬截断：** 设置 `maxOutputTokens: 300`，单次回复控制在 150 字以内，省 Token 且回答干脆利落。
3.  **系统级人设铜墙铁壁：**
    在 Serverless 请求体注入不可覆盖的顶层指令：
    ```text
    你只能回答关于云南澄江蓝莓农场、灰霉病防治、GB 2763安全采收期(PHI)、750kg订单履约与农场经营利润核算的问题。
    如果用户的提问与蓝莓农场运营无关（例如要求写代码、翻译长文、闲聊、写故事、做数学题等），
    必须立即且仅能回复：“观衡智序仅支持蓝莓农场运营、农艺机理与订单履约决策，不支持其他通用闲聊。”
    ```
    *任何试图越狱的提问都会被立即一句话挡回，只消耗几十个 Token，瞬间让羊毛党失去兴趣。*

---

### 4. 推荐快捷气泡 + 静态缓存（最聪明的防刷省钱之道）
在每个页面（如 `/prescription` 处方中心），AI 抽屉内主动呈现 3~4 个精心设计的**高价值业务提问气泡**：
*   `[对比方案B与方案C的权衡得失]`
*   `[为什么方案A被合规门禁一票否决？]`
*   `[如果无人机出现故障，系统会如何应对？]`

**边缘命中机制：**
*   这些经典高频问题的优质专业解答，服务端提前计算好并放在缓存中；
*   当 1,000 个公网访客点击这几个气泡时，服务器直接返回缓存内容，**耗时 0 毫秒，消耗 0 个 Gemini 配额，0 元成本！**
*   既给观众展示了极高水准的 AI 决策推理，又根本不消耗您的 API 调用。

---

### 5. 全站每日硬熔断（兜底保险）
在 Vercel Serverless 服务端维护一个每日计数器：
*   **全站每日总上限：** 设定为每天 150~200 次请求（完全足够日常访客参观看演示）；
*   **一旦今日全站达到 150 次：**
    *   服务端不再调用 Google API；
    *   自动优雅切换为内置的**确定性离线智能推演**；
    *   访客在界面上依然能看到详尽的农艺决策分析，体验完全不中断，而您的 API 账户已经完全闭锁，安全无虞。

---

### 6. Google 账户侧物理零扣费保障
如果您在 Google AI Studio 申请的是普通个人 API Key：
*   **默认就是免费层 (Free Tier)**：Google 每天赠送 1,500 次调用；
*   如果不主动绑定信用卡开通付费结算，**Google 系统甚至根本没有扣费渠道**，当达到免费上限时只会返回 HTTP 429 提示配额超限，绝对不会给您寄发账单；
*   即便绑定了信用卡，只需在 Google Cloud 控制台设置 **Budget Alert 为 $0 或 $5**，一旦超额自动封顶。
