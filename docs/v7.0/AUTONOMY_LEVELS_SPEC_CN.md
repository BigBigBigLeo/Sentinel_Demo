# Sentinel 7.0 自主决策分级与日常/危机双轨运行规范 (Autonomy Levels & Dual-Track Operations)

> **版本：** Sentinel Demo 7.0.0  
> **设计核心：** 日常未开启场景时 24/7 真实自主运行（小问题/黄色预警系统自主闭环执行）；开启场景或发生重大风险时触发重点红色警报并要求人工联锁授权。

---

## 一、 自主决策分级体系 (Autonomy Levels, L1 ~ L5)

Sentinel 借鉴自动驾驶 SAE 分级与工业过程自动化 (SCADA/DCS) 标准，在现代农业中确立五级决策自主权：

```
┌────────────────────────────────────────────────────────────────────────┐
│ 🟢 L1 · 数据感知与清洗 (Data & Filtering)                                │
│    传感器自动采集、噪声滤波、多模态数据对齐。100% 自动，无需人工介入。    │
├────────────────────────────────────────────────────────────────────────┤
│ 🟢 L2 · 常规环境巡航调控 (Routine Environmental Cruise)                 │
│    依据既定温湿度/光照区间，自动执行水肥微滴灌、早晚遮阳网开闭。常规绿色。 │
├────────────────────────────────────────────────────────────────────────┤
│ 🟡 L3 · 低中危微扰动自主闭环 (Autonomous Closed-Loop · 黄色预警)        │
│    【日常 24/7 核心】环境突变、局部微湿、阵风、低度虫情。AI 自主分析、   │
│    自主制定控制方案并下发 IoT/无人机执行，事后归档记录。无需打扰决策层。 │
├────────────────────────────────────────────────────────────────────────┤
│ 🔴 L4 · 复杂商业/农艺重大冲突决策 (Interlocked Human-in-the-Loop)      │
│    【开启 Scenario 或重大危机】病害暴发 (Score>60)、PHI 安全期冲突、     │
│    合同违约短缺风险。6 大专家会诊矩阵，A/B/C 横向对比，必须人工点击授权！ │
├────────────────────────────────────────────────────────────────────────┤
│ 🚨 L5 · 极端不可抗力应急熔断 (Emergency Fail-Safe Override)             │
│    设备断电、通讯中断、暴风雨极端天灾。安全停机与应急保障机制。         │
└────────────────────────────────────────────────────────────────────────┘
```

## 二、 双轨运行机制对照表 (Dual-Track Operation Matrix)

| 维度 | 轨道一：日常 24/7 运营模式 (Track 1: Normal Operations) | 轨道二：场景演练与重大危机模式 (Track 2: Scenario Crisis Mode) |
|---|---|---|
| **触发状态** | **默认常态**（用户未开启任何 Scenario 时系统自然流转）。 | **用户主动加载 Scenario**，或现场真实测得评分 >60 的复合重大危机。 |
| **警报级别** | 绿色正常 (Normal) / **黄色微预警 (Yellow Warning)**。 | **重点红色高危警报 (Red Critical Alert · Interlocked)**。 |
| **AI 决策自主权** | **L2 ~ L3 级完全自主闭环**：AI 自主研判并直接执行，自动消除波动。 | **L4 级人机联锁协同**：AI 列出专家共识与 A/B/C 方案，严格禁止自主下发。 |
| **界面视觉呈现** | 呼吸式微动态绿/蓝心跳灯，日志流中展示平稳推进，无全屏警报轰炸。 | 全屏/顶部高亮红色警报横幅，大号字体倒计时，指引前往 `/prescription`。 |
| **用户核心动作** | 无需做任何操作（可随时随地查看图表或打开 Ask Sentinel 追问）。 | 在 `/prescription` 审阅 3 套方案与 3 道门禁，亲手点击 `[⚡ AUTHORIZE DISPATCH]`。 |
| **执行载体** | 边缘 IoT 控制器（风机、水阀、遮阳帘）、机队常规巡航。 | 多角色协同（植保无人机局部喷药 + 人工精细剪枝 + 库容调度 + 质检复核）。 |

## 三、 日常 24/7 运营中的 4 个真实科学自主闭环场景 (Track 1 细节)

必须严格符合云南澄江蓝莓栽培生物学与大棚物理学规律，严禁虚构瞎编：

### 场景 1：午后大棚局部湿热自适应对流通风 (Heat & Humidity Micro-Ventilation)
- **物理与气象成因：** 云南澄江高海拔日照强烈，下午 13:00~14:00 大棚内部气温升至 27.2°C，果实蒸腾作用导致传感器 `H-01` 湿度测得 83.5%（略超 80% 警戒阈值，若持续 2 小时以上易诱发灰霉病孢子萌发）。
- **数据变化特征：** 湿度由 72% 逐步爬升至 83.5%，叶面湿度仪 `LW-01` 测得水膜凝结 0.8 小时。
- **AI 自主闭环链路（L3 级）：**
  1. `AI Watchdog` 捕捉到黄色预警指标。
  2. `Greenhouse Agronomist` 判定为常规温室效应水汽积聚，非真菌侵染。
  3. `Control Engineer` 自动生成调控策略：调度 2号/4号轴流风机以 65% 功率运转 20 分钟，开启顶部电动通风窗 30%。
  4. 监测结果：湿度在 15 分钟内平稳回落至 71.0%，叶面水膜消退，任务自动标记为 `COMPLETED`。
- **系统呈现与 AI 解释：**
  - Activity Rail 滚动一行精简日志：`[AUTO-RESOLVED] Microclimate ventilation executed. H-01 returned to 71.0%.`
  - Ask Sentinel 可对答：*"刚才自动启用了风机对流，用时18分钟消除了局部高湿，耗电 1.2 度，预防了病菌滋生。"*

### 场景 2：基质栽培蓝莓水分微亏缺脉冲补灌 (Substrate Moisture Pulse Fertigation)
- **物理与气象成因：** 蓝莓采用专用酸性草炭基质容器栽培，保水缓冲有限。传感器 `SM-02` 测得含水率跌至 27.5%（最佳范围 30%~35%）。
- **AI 自主闭环链路（L2 级）：**
  1. 滴灌控制器检测到水分阈值偏低，上报系统。
  2. 自动启动滴灌电磁阀 `VALVE-B3-W`，以 EC 1.2 mS/cm、pH 4.8 滴灌 12 分钟，补水 80 升。
  3. 传感器读数恢复至 33.2%，系统记入农资消耗账本，无须人工干预。

### 场景 3：外部短时阵风规避与巡检航线微调 (Gust Wind Avoidance & Autonomous Rescheduling)
- **物理与气象成因：** 对接 Open-Meteo 真实气象，当地午后出现 4.6 m/s 突发阵风（接近植保机安全抗风上限 5.0 m/s）。
- **AI 自主闭环链路（L3 级）：**
  1. `Remote Sensor Pilot` 自动检测到风速超限风险。
  2. 将原定 14:30 起飞的例行多光谱扫描航线自动推迟 30 分钟，并置机队状态为 `STANDBY`。
  3. 待 15:00 气象风速回落至 2.2 m/s 后自主起飞执行，并在执行日志中附上气象风速曲线合规凭据。

### 场景 4：智能诱虫板低密度微量萌芽处置 (Early Pest Sentinel & Trap Auto-Scouting)
- **物理与气象成因：** `TRAP-S02` 智能识别板通过边缘视觉识别出 3 只蓟马（日增量 2.0 只/板，处于初始萌芽期，远低于暴发阈值 10.0 只/板）。
- **AI 自主闭环链路（L2 级）：**
  1. 系统自动更新捕虫板历史基线，标记为黄色关注点。
  2. 自动派发次日例行巡检工人随行检查任务，无需启动任何化学或生物喷洒，保持农场零农残纯净状态。

## 四、 重大危机与场景演练模式 (Track 2 细节)

当用户点击右上角或菜单中的 **Scenario（如“灰霉病暴发与 750kg 订单履约危机”）** 时，系统立即进入最高决策指挥状态：

1. **红灯重点警报：**
   - 顶部和导航栏亮起红色警报指示器：`CRITICAL ALERT: Gray Mold (Score 68/100) breaches tolerance. Contract BB-ORDER-750-001 at Risk.`
2. **跳转处方中心与专家会诊（`/prescription`）：**
   - 呈现首屏 **Specialist Consensus Matrix（6 大专家共识）** 与 **方案 A/B/C 横向对比**。
   - 方案 A（全区化防）因触犯 14天 PHI 法律底线被判定为红标阻断；方案 B（隔离未染批次 LOT-01/02 放行，局部生物治理）被评为最优推荐。
3. **严格人机联锁（Interlocked Dispatch）：**
   - AI 被绝对禁止自动派发作业！
   - 必须由操作人员点击 `[⚡ AUTHORIZE DISPATCH (INTERLOCKED)]` 按钮，生成不可篡改密码学签名哈希后，工单方能进入 `/execution`。
