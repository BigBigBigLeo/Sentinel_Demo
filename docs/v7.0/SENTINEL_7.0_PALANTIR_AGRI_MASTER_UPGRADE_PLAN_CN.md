## 二、 市场情报中枢 (`/intelligence`) 的分型呈现与深度分析重构

不同类型的情报在农场经营中具有完全不同的决策传导链路，必须采用**不同的专业呈现形态与衍生推演分析**：

```

│ 观衡全域产业情报中枢 (Global Multi-Modal Intelligence Hub)                             │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ [顶栏核心宏观脉搏 KPI 磁贴]                                                            │
│ • 盒马KA订单锁定溢价: ¥65.0/kg (+20.3%)  • 节假日行情拉动效应: 五一前夕拉动 +28.5%    │
│ • 滇中产地一级收购基准: ¥54.2/kg         • 干线绿通物流在途指数: 延误风险中等(节前车流)│
└────────────────────────────────────────────────────────────────────────────────────────┘
```

### 2.1 维度一：气象物候行情报 (Meteo-Phenology INT) —— 趋势分析与农艺衍生推演
*   **呈现形态：** 7~14 天连续气象演变多轴时序图（Recharts：最高温、最低温、相对湿度、降雨概率、日照时数）+ 澄江抚仙湖 24h 高精雷达仪表。
*   **深层趋势分析与农艺推演：**
    *   **降雨与强对流预警：** 监测未来 48 小时阵风与突发暴雨概率。推演：“D+2 日 06:00~11:00 降雨概率 85%，露天区与敞开式棚室采收窗口关闭，建议提前 24 小时启动抢收或锁定温室连栋区”。
    *   **有效积温 (GDD) 与成熟度曲线：** 依据抚仙湖盆地温差（昼夜温差 14°C），推演华香品种果实糖度从 12.8°Bx 上升至 14.2°Bx 的峰值节点（预估 3 天后迎来盛果期）。
    *   **采收窗口综合评级 (Harvest Window Rating)：**
        *   `05:00 - 08:30`：【五星黄金期】气温 16~20°C，叶面露水适度蒸发，果粉（Wax Bloom）保护度达 98.2%；
        *   `11:30 - 15:30`：【高温红牌禁采】冠层温度超 29°C，采摘极易造成果实机械擦伤、表皮软化与果粉脱落，强制关闭采收调度。

### 2.2 维度二：大宗行情与节假日消费情报 (Market Dynamics & Holiday INT) —— 供需波峰与物流阻断推演
*   **呈现形态：** 30 天产销地价格发现时序图（产地收购价 vs 销地批发价 vs KA协议锁定保底价）+ 节假日时间轴标记（Holiday Horizon Overlay）。
*   **深层趋势分析与农事商业推演：**
    *   **节假日消费拉动模型 (Demand Surge Analysis)：**
        *   在即将到来的**清明节 / 五一黄金周 / 端午节**前 3~5 天，华东及华南高端商超（盒马、Ole'、山姆）鲜果礼盒采购量激增 +120%~+180%，特级大果（18mm+）采购溢价率提升至 +35%；
        *   **价格传导模拟：** 预测嘉兴一级批发市场价格将从当前的 ¥72.5/kg 脉冲式上涨至 ¥88.0/kg。
    *   **节假日货运拥堵与保鲜衰减风险 (Freight Delay & Cold Decay Risk)：**
        *   高速公路小客车免费与返乡潮导致滇沪干线、粤港澳干线货运耗时从常规的 28 小时激增至 38~44 小时（预期延误 +10~16 小时）；
        *   **衍生防范处方：** 必须要求冷藏车提级打冷（果心温由常规 2.5°C 降至 1.2°C），并在气调包装中加入微孔乙烯吸附膜，防止在途软化。

### 2.3 维度三：政策法规与合规情报 (Regulatory & Policy Impact INT) —— 条款穿透与业务冲击矩阵
*   **呈现形态：** 结构化卡片与因果推导矩阵（政策来源 ➔ 条文核心 ➔ 对 900 亩园区的连锁影响 ➔ 建议行动 ➔ 一键跳转）。
*   **深层分析案例：**
    1.  **国家农残限量新国标 GB 2763 增补修订：**
        *   *条文*：对蓝莓种植中新引入药剂的最低残留限量 (MRL) 收紧至 0.01 mg/kg；
        *   *影响分析*：南区 LOT-03 正在使用的乙基多杀菌素需延长 PHI 安全间隔期至严格 72 小时，绝对禁止提前采摘；
        *   *建议行动*：一键更新系统《管理配置》中的合规门禁规则 [RULE-THRIP-PHI-03]。
    2.  **云南省现代设施农业绿色电力阶梯补贴政策：**
        *   *条文*：夜间低谷电价时段 (23:00~07:00) 冷库打冷电价下浮 42%；
        *   *影响分析*：农场 300 吨保税气调库若将预冷储能集中在夜间完成，单批次（750kg）打冷能耗成本可由 ¥850 降至 ¥490，每月可省能耗开支 ¥32,000；
        *   *建议行动*：在方案 C 决策逻辑中提升夜间蓄冷权重。
    3.  **生鲜跨省绿通鲜活农产品电子验资免通行费政策：**
        *   *条文*：出具国家追溯平台电子批次检测报告与数字合格证的冷藏车辆免收高速通行费；
        *   *影响分析*：单趟滇沪冷链货车可免除过路费约 ¥2,400，但要求出场时必须携带 Sentinel 生成的 SHA-256 密码学质检存证凭证。

### 2.4 维度四：在途冷链与车厢温控态势 (Cold-Chain IoT INT) —— 动态物理闭环
*   **呈现形态：** 3 条干线车队实时监控卡片（车牌号、线路、车速、当前位置、果心温控曲线）。
*   **深层分析指标：**
    *   **鲁A·F8291 (澄江基地 -> 上海盒马大仓)**：冷藏箱均温 1.6°C（绿灯正常），预计 14 小时后抵达昆山生鲜大仓；
    *   **粤B·9210K (澄江基地 -> 广州江南批发市场)**：冷藏箱均温 2.1°C，冷机处于高能效巡航，在途温差 <0.5°C；
    *   **云A·8832C (基地 -> 昆明长水国际机场)**：恒温航空冷鲜箱，特大果直飞北京，果温 1.4°C，准时率 100%。
